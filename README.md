# 3D-PrintLab website

GitHub Pages-klare statische website voor `3d-printlab.nl`.

## Voor publicatie nog invullen
1. **WhatsApp:** zet in `assets/app.js` bij `whatsappNumber` je nummer in internationaal formaat, bijv. `31612345678`.
2. **Formulier + bestandsupload:** GitHub Pages is statische hosting. Koppel daarom `formEndpoint` in `assets/app.js` aan een externe veilige formulierbackend of serverless functie die uploads accepteert.
3. **Zakelijk e-mailadres:** voeg later `info@3d-printlab.nl` of vergelijkbaar toe.
4. **Portfolio:** vervang de tijdelijke visuals door eigen foto’s.
5. **Shop:** voeg echte producten, prijzen en checkout toe zodra het assortiment er is.
6. **Juridisch:** privacy en voorwaarden zijn conceptteksten; laat ze vóór commerciële ingebruikname controleren en vul bedrijfsgegevens aan.
7. **Logo:** de huidige kubus is een tijdelijke brand-mark en eenvoudig te vervangen door een SVG-logo.

## GitHub Pages
Upload alle bestanden naar de root van je repository. Kies daarna in GitHub: Settings → Pages → Deploy from branch → `main` / root. Het bestand `CNAME` staat al op `3d-printlab.nl`.
